# Health Stream Insight

Build a complete, functional academic dashboard titled Hospital Patient Flow & Disease Burden Explorer using React, TypeScript, and D3.js.

This is a Big Data Visualization project. The dashboard must analyse hospital admissions, disease distribution, patient demographics, department workload, monthly admission trends, and length of hospital stay.

Include:

KPI cards for total admissions, average length of stay, most common disease, and busiest department.

A D3 bar chart for admissions by disease.

A donut chart for patient age groups.

A stacked bar chart for department and admission type.

A monthly admissions line chart.

A horizontal bar chart for average length of stay by department.

Filters for date range, disease, department, age group, gender, and admission type.

Working filters, interactive tooltips, clickable legends, and a clear-all-filters button. All charts and KPI cards must update when filters change.

A responsive, professional healthcare analytics design with a light background, navy and teal accents, and readable labels.

Start with clearly labelled synthetic sample data. Do not present it as real hospital data. Keep the data in a separate file so it can later be replaced with a verified CSV dataset.

Important: Build a working dashboard, not just a visual mockup. Check that the preview renders, all charts display correctly, and the filters work. Fix any runtime errors before finishing.
